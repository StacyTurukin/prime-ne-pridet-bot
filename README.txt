ПРАЙМ НЕ ПРИДЁТ, ЕСЛИ ПРОСТО ЖДАТЬ — v3

Что теперь умеет бот:

ТУРНИК / БРУСЬЯ
- Каждый подход записывается отдельно.
- Считается сумма за день.
- Считается лучший подход за день.
- Если подход побил твой all-time PR — бот пишет старый → новый результат и дату.
- В «Статистика → История PR» лежит вся лестница рекордов по датам.
- Там же видны последние 14 дней в формате: всего / лучший подход.

СЕРИЯ ОБЯЗАТЕЛЬНОГО МИНИМУМА
- Цели отдельно: турник, брусья и общий силовой минимум.
- Когда минимум закрыт несколько дней подряд, бот выдаёт свежую ачивку каждый день:
  2 дня, 3 дня, 4 дня, 5 дней, 6 дней и так далее.
- В общей статистике есть текущая и лучшая серия.

ГИРЯ
- Обычные записи остались.
- Новый режим: Записать → Гиря → Собрать комплекс.
- Один раз задаёшь вес.
- Один раз собираешь упражнения одного круга, например:
  goblet 10, махи 16, рывок 5.
- Потом выбираешь число кругов, например 3.
- Бот сам пишет 30 / 48 / 15 повторений и сохраняет весь комплекс.
- Последние комплексы лежат в «Статистика → Комплексы».

ЛИЦЕВАЯ ГИМНАСТИКА
- Отдельная кнопка «🙂 Лицо».
- Можно отметить: Лоб / Глаза / Щёки / Овал + шея / Массаж.
- По умолчанию обязательного минимума нет.
- В «Настройки → Минимум лица» можно поставить 1–5.
- Если минимум включён, он появляется в сегодняшнем прогрессе и напоминаниях.

БЕГ
- Место: стадион / техникум / трейл / другое.
- Дистанция.
- Общее время.
- Автоматический средний темп и скорость.
- Сложность 1–5.
- Сравнение с предыдущей пробежкой.
- Цель по умолчанию: 11 км из 60 минут.
- Лучший темп, максимальная дистанция, километры за 7 дней.
- Если новая пробежка хуже по темпу или короче предыдущей —
  бот может прислать «мне похуй, я завтра ещё раз попробую» или «я кринж».

ОБЩАЯ СТАТИСТИКА
- Всего подтягиваний.
- Всего брусьев.
- Общий силовой объём.
- Повторы с гирей.
- Количество гиревых комплексов.
- Километры и число пробежек.
- Общее время бега.
- Литры воды.
- Лицевая гимнастика.
- Текущая и лучшая серия.
- Дни с записанной активностью.

МЕДИА
- Присланные мемы встроены в media/.
- На новый PR бот кидает один из рекордных мемов.
- На просевший бег — setback-мем.
- На крупные ачивки может прилететь achievement.mp4.
- Из присланного ролика извлечён короткий achievement_track.mp3.
- Йога-ачивка использует meditation.mp4.

ЛОКАЛЬНЫЙ ЗАПУСК
1. Распакуй архив.
2. Открой PowerShell в папке.
3. Выполни:
   Set-ExecutionPolicy -Scope Process Bypass
   .\run.ps1
4. Первый запуск создаст .env.
5. Открой .env и вставь BOT_TOKEN.
6. ADMIN_USER_ID можно сначала оставить 0.
7. Снова .\run.ps1
8. В Telegram: /start
9. Команда /myid покажет твой ID.
10. Впиши его в ADMIN_USER_ID и перезапусти бота — заработает админка.
